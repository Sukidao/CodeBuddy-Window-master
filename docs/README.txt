CodeBuddy 窗口书签
==================

一个帮你记住项目窗口、一键全部打开的小工具。
绿色单文件，不需要安装。

【快速上手】
1. 把本文件所在的整个文件夹放到有写权限的地方，
   例如 D:\Tools\CodeBuddyBookmarks（不要放 C:\Program Files）。
2. 双击 CodeBuddyWindowMaster.exe 打开程序。
3. 第一次运行时列表可能为空：
   - 点「导入当前窗口」把正在运行的窗口收进来
   - 或点「添加文件夹」挑选项目目录
4. 之后：勾选若干项 → 点「打开选中」；想全开 → 点「全部打开」；
   只想开一个 → 双击那一行。

【已打开的窗口会置顶】
点击一个“已经打开”的书签时，程序不会重复开窗，
而是把那个窗口还原并切换到最前面，方便你快速找到它。
（界面上的「已打开的窗口置顶」可关闭此行为）

【快捷键】
F5        刷新
Ctrl+F    搜索
Ctrl+A    全选勾选
F2        重命名选中行
Enter     打开选中行
Delete    删除选中行

【托盘】
点最小化 → 缩到右下角通知区：
· 双击图标            恢复主界面
· 右键图标            书签列表 / 未加书签的窗口 / 全部打开 / 开机自动启动 / 退出
最小化到托盘后，5 秒自动刷新会暂停，恢复界面后继续。

勾选「开机自动启动」后，登录 Windows 时会静默启动到托盘，
不会弹出主窗口（菜单里的勾选状态会随系统设置变化）。

【窗口大小记忆】
手动调整窗口大小或位置后会自动记住（关闭时和拖拽结束时各存一次），
下次打开恢复成一样的大小。删掉 ui-state.json 可回到默认尺寸。

【数据保存在哪】
exe 同目录下的 bookmarks.json，每次修改自动保存；
窗口位置大小存在同目录的 ui-state.json。
删掉 bookmarks.json 即恢复出厂状态（下次启动会重新导入当前窗口）。
注意：书签里存的是绝对路径，换电脑后需要重新添加。

【系统要求】
Windows 10 / 11 可直接运行（系统自带 .NET Framework 4.8）。
Windows 7 / 8 需要先安装 .NET Framework 4.x。
32 位、64 位系统都支持。

【支持哪些 IDE】
CodeBuddy CN、WorkBuddy、Trae CN、VS Code。
远程 SSH 窗口也支持（用 --folder-uri 打开）。

【打不开或找不到 IDE？】
程序按以下顺序查找 IDE 的安装位置：
1. 常见安装目录（%LOCALAPPDATA%\Programs\CodeBuddy CN 等）
2. 注册表 App Paths
3. 注册表卸载信息里的 InstallLocation / DisplayIcon
4. 开始菜单快捷方式
如果 IDE 装在非常规位置仍找不到，可以手动把它加入书签后反馈。

【安全提示】
程序只读取 IDE 自己的状态文件，不联网、不上传任何数据。
exe 未做数字签名，首次运行若被 SmartScreen 拦截，
点“更多信息 → 仍要运行”即可。
